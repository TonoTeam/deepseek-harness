# Agent Note：MCP 工具目录轮询

Status: implemented

[English](2026-10-12-mcp-tool-list-polling.md) | 中文

## 问题

无状态 HTTP MCP 端点无法在账号连接电脑或修改权限后通知已连接的 Agent。通过重连刷新目录可能中断进行中的工具调用。

## 决定

MCP 客户端提供可选的 `toolListRefreshMs`，支持不能发送目录变更通知的无状态服务器。零保留仅通知驱动的行为；正整数间隔通过与通知相同的同步队列轮询现有连接。每次间隔从前一次请求结束后计算，避免定时请求堆积。发现失败保留上一代目录；每次工具调用的授权仍由远端执行器检查。

## 影响

连接代断开或插件卸载后轮询停止。恢复连接在初始发现成功后重新启用轮询。目录更新不会关闭连接或取消正在执行的调用。[轮询测试](../../../../packages/mcp/mcp-client/tests/polling.spec.ts)覆盖可选启动恢复、目录新增与移除、发现失败、串行化、进行中的调用及卸载。

## 考虑过的替代方案

重载插件会关闭连接，可能取消长调用。产品自行复制桥接实现会重复工具转换和连接管理。轮询现有桥接复用其串行发现与卸载机制。
